GPsen — 05 Backend Schema (base de données) Projet : GPsen — plateforme web de groupage participatif Version : 1.0 — 23 octobre 2026 Dépend de : 01 PRD, 02 TRD, 03 AppFlow Ce document est la source de vérité de la base de données MySQL (utf8mb4, moteur InnoDB ). L'assistant de code doit créer les migrations Laravel exactement selon ces tables. Il sert aussi de base au MCD / MLD du chapitre 3 du mémoire. 1. Conventions Noms de tables et colonnes en anglais , snake_case , tables au pluriel. Clé primaire id (BIGINT UNSIGNED, auto- incrément ) ; created_at et updated_at sur toutes les tables métier. Clés étrangères nommées &lt; table_singulier &gt;_id avec contrainte d'intégrité. Valeurs d'énumération stockées en chaînes françaises sans accent (identiques aux Enums PHP du TRD), colonne string validée côté application (pas de type ENUM MySQL, pour faciliter les migrations). Montants en FCFA, entiers (pas de décimales). Poids en kg avec 2 décimales. Aucun champ de rôle ou de statut modifiable depuis un formulaire public. 2. Table en ajout seul : jamais de modification ni de suppression. 4.6 reviews Colonne Type Contraintes Description id BIGINT UNSIGNED PK shipment_request_id BIGINT UNSIGNED FK → shipment_requests.id, ON DELETE CASCADE author_id BIGINT UNSIGNED FK → users.id, ON DELETE CASCADE target_id BIGINT UNSIGNED FK → users.id, ON DELETE CASCADE Personne notée rating TINYINT UNSIGNED NOT NULL, 1 à 5 comment VARCHAR( 500) NULL created_at / updated_at TIMESTAMP NULL Contraintes : UNIQUE( shipment_request_id , author_id ) , INDEX( target_id ) . Un avis n'est possible que si la demande est livree et que l'auteur est l'une des deux parties. 4.7 reports Colonne Type Contraintes Description id BIGINT UNSIGNED PK reporter_id BIGINT UNSIGNED FK → users.id, ON DELETE CASCADE target_user_id BIGINT UNSIGNED FK → users.id, NULL, ON DELETE SET NULL trip_id BIGINT UNSIGNED FK → trips.id, NULL, ON DELETE SET NULL shipment_request_id BIGINT UNSIGNED FK → shipment_requests.id, NULL, ON DELETE SET NULL reason VARCHAR( 40) NOT NULL arnaque , comportement , colis_non_livre , fausse_information , autre description TEXT NOT NULL status VARCHAR( 20) NOT NULL, défaut ouvert ouvert , en_cours , traite admin_note TEXT NULL Note interne handled_by BIGINT UNSIGNED FK → users.id, NULL, ON DELETE SET NULL created_at / updated_at TIMESTAMP NULL Index : INDEX( status, created_at ) . Contrainte applicative : au moins une des trois cibles ( target_user_id , trip_id , shipment_request_id ) est renseignée. 4.8 Tables fournies par Laravel notifications (canal base de données ) : id UUID, type , notifiable_type , notifiable_id , data JSON, read_at , created_at , updated_at . password_reset_tokens , sessions , cache , jobs , failed_jobs , migrations : générées par Laravel, à ne pas modifier. 5. Relations Eloquent Modèle Relations User hasOne ( GroupeurProfile ) , hasMany ( Trip, ' groupeur_id ') , hasMany ( ShipmentRequest , ' sender_id ') , hasMany ( Review, ' author_id ') , hasMany ( Review, ' target_id ') , hasMany ( Report, ' reporter_id ') GroupeurProfile belongsTo ( User) , belongsTo ( User, ' validated_by ') Trip belongsTo ( User, ' groupeur_id ') , hasMany ( ShipmentRequest ) ShipmentRequest belongsTo ( Trip) , belongsTo ( User, ' sender_id ') , hasMany ( ShipmentStatusHistory ) , hasMany ( Review) ShipmentStatusHistory belongsTo ( ShipmentRequest ) , belongsTo ( User, ' changed_by ') Review belongsTo ( ShipmentRequest ) , belongsTo ( User, ' author_id ') , belongsTo ( User, ' target_id ') Report belongsTo ( User, ' reporter_id ') , belongsTo ( User, ' target_user_id ') , belongsTo ( Trip) , belongsTo ( ShipmentRequest ) Scopes utiles : Trip::open() (statut ouvert et départ ≥ aujourd'hui), Trip::search($origin, $destination, $date) , ShipmentRequest::pendingForGroupeur($id) . 6. Calculs et règles d'intégrité Capacité restante d'un trajet SELECT t.capacity _kg - COALESCE(SUM( r.weight _kg ), 0) AS remaining_kg FROM trips t LEFT JOIN shipment_requests r ON r.trip _id = t.id AND r.status IN (' acceptee ',' collectee ','en_transit',' livree ') WHERE t.id = : trip _id GROUP BY t.id; Acceptation sans surbooking : dans une transaction, verrouiller la ligne du trajet ( lockForUpdate ), recalculer la capacité restante, accepter seulement si weight_kg &lt;= remaining_kg , puis passer le trajet à complet si le reste est nul. Note moyenne : après chaque avis, average_rating et ratings_count du profil de la personne notée (si groupeur) sont recalculés depuis reviews . Livraisons : passage d'une demande à livree incrémente delivered_count du groupeur. Suppression : pas de suppression d'utilisateur en production ; on suspend . Les cascades ne servent qu'aux tests et au nettoyage de la base de démonstration. 7. Jeux de données (seeders) Seeder Contenu AdminSeeder 1 administrateur (e-mail et mot de passe de démonstration dans .env , jamais en dur dans le dépôt) DemoUsersSeeder 5 expéditeurs, 4 groupeurs validés, 1 groupeur en attente, 1 groupeur refusé, 1 compte suspendu DemoTripsSeeder 8 à 10 trajets réalistes (Dakar ↔ Paris, Dakar ↔ Casablanca, Dakar ↔ Bruxelles, etc.) avec des dates futures et des statuts variés DemoRequestsSeeder Demandes à tous les statuts, avec historique cohérent, dont 3 livrées avec avis DemoReportsSeeder 2 signalements ouverts , 1 traité Les dates des trajets sont générées relativement à la date du jour (« dans 5 jours », « dans 12 jours ») pour que la démo reste valide le jour de la soutenance. Commande de réinitialisation : php artisan migrate:fresh --seed . 9.
